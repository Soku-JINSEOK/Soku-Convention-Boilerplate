# Release record reading guide

> **Document purpose:** Release index. Find the compatibility and migration record for a particular artifact version.
>
> **Key point:** A historical record describes that version, not the latest release or today's deployment state.

Convention tags and CLI tags are independent. Read the record matching the
artifact you intend to consume, then check its compatibility and migration
conditions. The reviewed current identity is in
[release-identity.json](../../release-identity.json); operating rules are in
[Release and Sync](../standards/RELEASE_AND_SYNC.md).

The records below retain their original content under the repository's
immutability and append-only rules. This adjacent summary provides orientation
without changing historical release evidence or signer history.
